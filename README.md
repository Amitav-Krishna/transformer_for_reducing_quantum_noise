# Frobenius Normalization for Quantum State Denoising

Code and paper for *Frobenius Normalization Enables Stable Training for Quantum State Denoising*.

## Directory Structure

- **`known_good/`** — Final paper PDF, verified code, and reproduction instructions. Start here.
- **`wip/`** — Active working directory for the paper source (`paper_v5.org`) and build scripts.
- **`archive/`** — Previous paper versions, old experiments, and deprecated code.
