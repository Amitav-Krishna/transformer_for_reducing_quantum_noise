PROBLEM:
  Model outputs constant I/32 (maximally mixed state) for ALL inputs
  Fidelity: ~0.031 ± 0.0002 (should vary 0.03-0.07+ like MLP)
  Training: Val loss 0.823 → 0.823 (ZERO improvement over 24 epochs)

ROOT CAUSES (in order of severity):

  1. DEGENERATE DECODER [CRITICAL]
     Line 102: dec = self.decoder(enc, enc)

     Problem: Using encoder output as BOTH tgt and memory
     - Self-attention on enc, then cross-attention to... same enc
     - Redundant operations, no bottleneck
     - Can learn identity or uniform output easily

  2. NO GLOBAL MIXING [CRITICAL]
     Lines 105-107: Per-row output projection

     Problem: Each row's 32 outputs computed independently
     - Row 0: f(row_0_embedding) → 32 values
     - Row 1: f(row_1_embedding) → 32 values
     - Rows cannot coordinate for Cholesky factorization
     - ρ[i,j] = Σ L[i,k] × L[j,k]* requires L[i] and L[j] to coordinate

  3. CLS TOKEN DISCARDED [CRITICAL]
     Line 105: row_output = dec[:, 1:, :]  # skip CLS

     Problem: Global aggregation token thrown away
     - CLS could provide global mixing needed
     - Instead, only local row embeddings used
     - The one component that could save the architecture is unused

EVIDENCE:

  Training Curves:
    Transformer: 0.8233 → 0.8237 (Δ = 0.0004) ← FLAT
    MLP:         0.8331 → 0.7990 (Δ = 0.0341) ← LEARNING

  Fidelity Results:
    Transformer: 0.031 ± 0.0002 (constant across ALL noise types/levels)
    MLP:         0.03-0.07 range (varies meaningfully with noise)

  Maximally Mixed State:
    I/32 has diagonal elements = 1/32 = 0.03125
    Observed fidelity ≈ 0.031 ← Almost exactly 1/32!

WHY MLP WINS:

  MLP: Linear(2048 → 128 → 142 → 1024)
    ✓ Forced global bottleneck (128 dims)
    ✓ All 1024 outputs from same 142-dim representation
    ✓ Global coordination for Cholesky
    ✓ Simple gradient path

  Transformer: (2048) → Enc(2112) → Dec(2112) → Per-row(1024)
    ✗ No bottleneck (expansion 2048→2112)
    ✗ Each row's output independent
    ✗ No global coordination
    ✗ Complex 10-layer gradient path

FIXES (pick one):

  Option 1 - Use CLS token (minimal change):
    cls_output = dec[:, 0, :]  # DON'T skip CLS
    chol_params = nn.Linear(embed_dim, 1024)(cls_output)

  Option 2 - Fix decoder:
    queries = nn.Parameter(...)  # Learned queries
    dec = self.decoder(queries, enc)  # NOT decoder(enc, enc)

  Option 3 - Encoder-only with bottleneck:
    enc = encoder(x)
    bottleneck = pool(enc)  # Force compression
    expanded = expand(bottleneck)
    dec = encoder(expanded)  # Second encoder
